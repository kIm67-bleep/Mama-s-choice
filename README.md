# Mama's Choice Millers Website

This version uses the structural/UX approach of the Capwell Industries website as a reference:
- utility contact bar
- corporate navigation
- large editorial hero
- product/category presentation
- company story
- values
- mission/vision
- strong CTA
- detailed footer

It does NOT copy Capwell's text, branding, logo, or proprietary imagery. All company content is for Mama's Choice Millers.

Open `index.html` in a browser to preview.
